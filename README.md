# Tema WordPress: portada en español de FySelf

Tema clásico instalable que reproduce **solo la portada en español** de [fyself.com/es](https://fyself.com/es/). El contenido, las imágenes, el vídeo, los estilos y los scripts necesarios para mostrar la página están incluidos localmente en `assets/`; los botones y enlaces de producto siguen apuntando a las páginas oficiales de FySelf.

## Instalación

1. En WordPress, abre **Apariencia → Temas → Añadir tema → Subir tema**.
2. Selecciona el archivo ZIP del tema y pulsa **Instalar ahora**.
3. Activa **FySelf — Portada en español**.

El archivo `fyself-homepage-es-wordpress.zip` se distribuye aparte de este repositorio para que puedas subirlo directamente desde el administrador de WordPress. Al activar este tema, WordPress usará la réplica para la página de inicio. El contenido de la copia es estático dentro del tema; no se edita con Elementor ni desde el editor de páginas.

## Alcance y atribución

Este es un proyecto independiente y no oficial. Se replica únicamente la página de inicio pública en español, no el sitio completo ni su panel de WordPress. FySelf, sus marcas, textos, fotografías, logotipos, iconos, vídeos y demás materiales pertenecen a sus respectivos titulares. Este repositorio no concede derechos adicionales sobre ese contenido ni implica afiliación o respaldo de FySelf.
